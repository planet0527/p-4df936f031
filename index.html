この作品について

ARTIFICIAL ECOSYSTEM は、植物・草食生物・捕食者が暮らす世界を観察する、ブラウザで動く人工生命シミュレーターです。生物は食べ物を探し、エネルギーを消費し、繁殖し、寿命を迎えます。子は親から遺伝子を受け継ぎ、突然変異や環境によって集団の特徴が少しずつ変化します。

目標スコアやクリア条件はありません。あなたは世界の観測者であり、環境を変える実験者です。同じ世界が、いつも同じ未来になるとは限りません。

はじめの3ステップ

  1. まずは眺める：ミント色が草食生物、ピンク色が捕食者、黄緑色の点が植物です。個体数と時間の変化を観察します。
  2. 生物を選ぶ：観察画面で生物をクリック／タップ。年齢・遺伝子・世代・祖先を右側の「個体観察」で確認できます。
  3. 環境を変える：「＋ 植物」「雨を降らす」「干ばつ」、地形ブラシなどを使い、変化を比べてみましょう。

画面の見方・操作

時間操作

一時停止、1～16倍速、1ステップ実行ができます。長い世代変化を速送りで観察できます。

BIOME LAB / 地形

観察・森林・草原・砂漠・水域・岩地を選択。観察画面をドラッグすると地形を塗れます。地形により植物の育ちやすさや移動が変わります。

ENVIRONMENT / 環境

植物の再生速度、突然変異率、気温を変更できます。季節は時間の経過で自動的に移り変わります。

BEHAVIOR LAB / 行動

危険地点の記憶や捕食者の追跡予測を切り替え、行動の違いを観察できます。

RESEARCH LAB / 研究

出生・死亡、平均世代、遺伝形質の変化を確認。観測データをCSVで書き出せます。

TIME MACHINE / 時間

過去の記録を選び、世界をその時点へ復元できます。戻した後は別の未来を試せます。

生き物の仕組み

  • 食物連鎖：植物 → 草食生物 → 捕食者。資源不足や捕食により個体数が変動します。
  • 遺伝と繁殖：条件を満たした同種の2個体が近づくと子を残せます。子は両親の特徴を組み合わせて受け継ぎます。
  • 自然選択：速度・視野・代謝効率などが生存や繁殖に影響します。ただし特定の進化が必ず起こるわけではありません。
  • 学習と記憶：草食生物は危険だった地点を記憶し、捕食者は獲物の移動方向を考慮して追跡できます。
  • 病気と環境：感染症、気温、季節、地形が生態系に影響します。生物が絶滅することもあります。

試してみたい観察実験

  1. 食料実験：植物の再生速度を上げて、草食生物と捕食者の数がどう変化するか観察。
  2. 砂漠実験：森林を砂漠に塗り替え、食料や生存率の変化を比較。
  3. 学習実験：危険地点の記憶をON/OFFして、草食生物の移動パターンを比較。
  4. 時間分岐：時間の記録から戻り、異なる環境操作を行って別の経過を観察。

保存・データについて

「世界を保存」はブラウザ内の保存領域に記録します。「世界をJSON出力」はファイルとして保存でき、別のブラウザでの復元にも使えます。観測結果はCSV出力できます。端末やブラウザの設定によっては保存が消えることがあるため、大切な世界はJSONでも保存してください。

ご注意：本作は創作・学習向けの簡略化されたモデルです。実際の生態学・遺伝学・疫学を厳密に再現するものではありません。時間を戻した場合も、乱数まで含めた完全な再現は保証されません。
