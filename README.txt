ARTIFICIAL ECOSYSTEM v1.0 — RELEASE EDITION

使い方:
1. index.html をブラウザで開きます。
2. 初回ガイドを読み、観測画面の生物を選択して情報を見ます。
3. 地形や気候、植物の量を変更して生態系の変化を観察します。

v1.0 の改善:
- 60秒間隔・画面を閉じる際の自動保存と復元ボタン
- JSON保存時の学習・追跡予測設定の保持
- 草食生物の採食処理、絶滅判定、寿命判定の不具合修正
- タッチ操作とスマホ表示の調整
- 未使用の描画処理を整理
- 初回チュートリアル、詳細ヘルプ、研究CSV、時間の記録を収録

注意:
- ブラウザの保存領域が使えない環境ではJSONで保存してください。
- ファイルを移動した場合やブラウザが異なる場合、ブラウザ内保存を共有できないことがあります。
- Node.js構文チェックは通過。Chromiumヘッドレス検証は実行環境のGPUプロセス起動失敗で未完了です。
- 科学的に厳密な進化・生態学の再現ではなく、創作向け簡易シミュレーションです。
